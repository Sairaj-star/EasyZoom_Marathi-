# EasyZoom (मराठी आवृत्ती)

ही सोपी आणि सर्वांना वापरता येणारी स्थिर वेबसाइट आहे. पूर्ण Zoom आमंत्रण लिंक किंवा मीटिंग ID/पासकोड वापरून मीटिंग उघडण्यास मदत करते आणि Zoom च्या अधिकृत डाउनलोड पेजकडे मार्गदर्शन करते.

## संगणकावर सुरू कसे करावे
1. ZIP फाइल Extract करा.
2. `index.html` फाइल आधुनिक ब्राउझरमध्ये उघडा. किंवा VS Code मध्ये फोल्डर उघडून स्थानिक static server वापरा.
3. यासाठी backend, package installation, API key किंवा सशुल्क सेवा आवश्यक नाही.

## मोफत ऑनलाइन प्रकाशित करा
`index.html`, `styles.css` आणि `script.js` या फाइल्स GitHub repository मध्ये ठेवा. त्यानंतर GitHub Pages किंवा इतर static hosting सेवा वापरून वेबसाइट प्रकाशित करू शकता.

## महत्त्वाच्या मर्यादा
- EasyZoom स्वतःहून Zoom इन्स्टॉल करू शकत नाही. अ‍ॅप स्टोअर किंवा ऑपरेटिंग सिस्टिम अतिरिक्त पुष्टी मागू शकते.
- ब्राउझरमधून मीटिंगमध्ये सहभागी होता येईल की नाही हे Zoom चा सपोर्ट, डिव्हाइस/ब्राउझर आणि होस्टच्या सेटिंग्जवर अवलंबून असते.
- मीटिंग ID/पासकोड वापरून अधिकृत Zoom लिंक तयार केली जाते. Zoom पुन्हा पासकोड किंवा इतर पडताळणी मागू शकते.
- EasyZoom मीटिंगची माहिती सर्व्हरवर पाठवत नाही किंवा जतन करत नाही.
- Zoom ही तृतीय-पक्ष सेवा आहे. EasyZoom चा Zoom शी अधिकृत संबंध नाही.
